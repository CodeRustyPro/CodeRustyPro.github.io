This page arrives in a single network round trip — a few kilobytes, no web fonts, no frameworks, nothing fetched before it paints — and the box above is built from your browser's real timing of that delivery. The XDP_PASS → maglev line runs a genuine Maglev consistent-hashing table, the same algorithm as the load balancer I'm building: it pins you to a stable backend, and if you kill one, only ~1/N of visitors move.
